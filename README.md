# CRUD de Produtos

Projeto desenvolvido para praticar Java, Programação Orientada a Objetos, testes automatizados e controle de versão com Git.

## Tecnologias

- Java 21
- Maven
- JUnit 5
- Git e GitHub

## Funcionalidades

- [x] Estrutura inicial do projeto
- [x] Teste automatizado de exemplo com JUnit 5
- [ ] Cadastrar produtos
- [ ] Consultar produtos
- [ ] Atualizar produtos
- [ ] Excluir produtos
- [ ] Testar as operações do CRUD

## Testes

Os testes são escritos com JUnit 5 e podem ser executados pelo IntelliJ IDEA.

Quando o Maven estiver configurado para execução pelo terminal, também será possível executá-los com:

```bash
mvn test
```
